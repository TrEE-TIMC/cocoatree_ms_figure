# COCOA-Tree: Phylogenetic visualization and comparative analysis of coevolving residues

This git repository contains all the code to reproduce the precise figures of
Jullien et al.

- `data` contains part of the data. The rest is provided in the cocoatree library.
- `scripts` contains all the scripts used to run the analyses and plot the figures
- `doc` contains mostly the first main figure of the article
